# 2026-10-16 — 초상화 게임북 UI

## 요청과 범위

사용자가 선호한 시안의 중앙 게임북 구도를 실제 Unity 튜토리얼에 구현했다. 정식 그림체는 서브컬처풍으로 예정하며, 사용자가 허용한 기존 밈 고양이 이미지를 임시 초상화로 사용했다. 튜토리얼 사건·합법 행동·정보 조합·저장 형식은 변경하지 않았다. 삭제와 본편 첫 조우는 여전히 후속 범위다.

## 변경 내용

- TutorialView: 좁은 중앙 읽기 열, 중앙 정렬 장소 제목, 상황 설명 → 초상화 → 인물 이름/대사 → 회색 세로 선택지. 하단 기록장/소지품/로그/설정 유지.
- 상황 설명과 대사를 순서대로 타이핑한다. 클릭/Space는 현재 표시 구간 완성 또는 다음 페이지 이동이며, 모든 읽기가 끝나야 행동을 허용한다. 메뉴에서 즉시 표시를 켜면 두 구간 모두 완성한다.
- 직접 입력창은 선택지 영역을 대체하고, 근거 첨부는 하단 별도 줄에 둔다. 반복 안내와 개발 상태 메시지는 평소 화면에서 줄이고 현재 목표는 소지품 안으로 옮겼다.
- GamebookContent: 첫 큰따옴표 앞의 짧은 설명만 분리한다. 긴 설명/높이 초과 설명은 원문 페이지 본문으로 돌아가며 서술 순서를 바꾸지 않는다. 기존 대화 기록과 저장은 보존한다.
- TutorialPortraitCatalog와 Resources/UI/TutorialPortraits.asset: 인물 이름별 Sprite 연결. Inspector에서 정식 일러스트로 교체 가능. 새 고양이 파일을 복제하지 않고 기존 Sprite를 참조한다.
- SoftPortrait: CanvasRenderer를 사용하는 UI 메시로 비율 유지와 가장자리 페이드. 알 수 없는 인물·이미지 누락·조사 장면·450자 이상 글에서는 텍스트 전용 배치를 사용한다. 카탈로그 매핑이 없으면 알려진 NPC는 기존 고양이로 대체한다.
- TutorialUIPreview: 아침 첫 화면, 직접 입력, 배송 대화, 기록장, 로그, 소지품, 긴 본문 PNG를 별도 Preview Scene에서 출력한다. 입력창과 선택지 비중첩, 초상화 연결, 조사 장면의 이전 초상화 제거를 검사한다.
- 새 Assets와 폴더에 .meta 포함. README, UI 사용·초상화 교체 안내, 실행 안내, 구현 명세 갱신. AGENTS.md는 변경하지 않았다.

## 검증

- 순수 코어 NUnit 독립 실행 35개 통과(본문 분리 테스트 3개 추가).
- 기존 1막 회귀 검사 통과: 도달 가능한 56개 상태 탐색.
- Unity 6000.3.6f1 실제 스크립트 import/컴파일과 Preview Export 종료 코드 0. 로그의 Reader checks passed 및 UI previews exported 확인.
- Logs/ui-preview/의 morning.png, dialogue.png, input.png, journal.png, reader-long.png를 직접 열어 초상화·한글·선택지·첨부·기록장 배치 확인. 아침 초상화에 필요한 CanvasRenderer 누락을 발견해 보완 후 재렌더링했다.
- 실제 API 호출, 사용자 저장 초기화, 활성 씬 수정, Git 커밋/푸시는 하지 않았다. 미리보기는 일회용 메모리 상태를 사용한다.
- 검증 기준은 1440×900 편집기 렌더링이다. 실제 Play에서의 키보드 포커스·마우스 조작과 다른 해상도, 실제 AI 응답은 별도 수동 확인이 필요하다. Unity 라이선스 서비스의 토큰 경고가 있었으나 권한 확인 후 컴파일/렌더링은 정상 완료했다.

## 다음 단계

SampleScene에서 실제 읽기 속도와 선택지 클릭을 확인한 뒤 정식 초상화를 연결한다. 현재는 정적 초상화이며 표정별 전환·Live2D·립싱크는 구현하지 않았다. 임시 이미지의 배포 사용 권한은 확인하거나 정식 제작물로 교체한다. UI 사용성 확인 후 튜토리얼 문장과 사건 배치를 다듬고, 월드 삭제와 첫 적대 조우를 별도 단계로 확장한다.
