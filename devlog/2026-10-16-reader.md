# 2026-10-16 — 텍스트 뷰어형 UI

## 요청

중앙 타이핑 본문 → 표시 완료 후 선택지 → 하단 고정 메뉴 구조로 변경.

## 구현

- TutorialView: 중앙 최신 장면, TMP 문자 수 기반 점진 표시, 긴 본문 페이지 분할.
- 마지막 페이지 완료 후 선택지/직접 입력/근거 제시 노출. 입력창은 별도 펼침.
- 클릭/Space로 현재 페이지 완성 또는 다음 페이지. 같은 프레임 중복 넘김 방지.
- 하단 기록장·소지품·대화 로그·설정. 모달 중 타이핑 정지와 뒤쪽 입력 차단.
- 소지품은 확실한 현재 소유물만 표시. 실제 아이템 사용/장비 교체는 미구현.
- 느리게/보통/빠르게, 즉시 표시. PlayerPrefs로 사용자 설정 유지.
- 본문 객체 변경에만 타이핑 재시작. 기록/설정 열기로 리셋되지 않음.
- AI 대기와 타이핑 구분. 게임 진행·저장 포맷·증거 연결 규칙은 유지.
- TutorialCore/TextReveal.cs 및 meta 추가. 시간 누적·완성·페이지 초기화 테스트 추가.
- TutorialUIPreview: 뷰어/기록장/로그/소지품/긴 본문 이미지와 선택지·페이지 검사 추가.
- README, UI 안내, 구현 명세, 플레이테스트 문서 갱신.

## 검증

- 전체 런타임 스크립트 독립 컴파일 통과.
- NUnit 32개 통과: 기존 27개 + 타이핑 관련 5개.
- 별도 Unity 렌더링 시도는 프로젝트를 연 사용자 에디터가 있어 종료 코드1로 중단됨. 에디터를 강제 종료하지 않았다.
- 이번 뷰어 UI의 새 이미지는 아직 렌더링 확인하지 못했다. 이전 UI PNG는 이번 결과가 아니다.
- Play 종료 후 재시작하여 타이핑/페이지/메뉴/입력의 실제 동작을 확인해야 한다. 편집기 Tools/Tutorial/Export UI Previews로 현재 버전의 이미지와 추가 검사를 실행할 수 있다.
- 실제 API 호출, 저장 초기화, Git 커밋/푸시는 하지 않았다.
