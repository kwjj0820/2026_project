# 2026-10-16 — 대화 화면 및 기록장 개편

## 목표

기능 검증용 상시 다중 패널에서 대화 중심 게임 화면으로 전환한다. 사건과 저장 데이터는 유지한다.

## 변경

- `TutorialView`: 대화 중앙 배치, 화자/본문 분리, 하단 입력, 두 열 행동 목록.
- 상단 기록장 버튼 → 종이색 별도 모달. 전체/증언/증거/관찰 필터와 상세·연결·수단 목록.
- 활용 수단 선택 시 기록장을 닫고 입력창 위에 첨부. 해제와 직접 제시 지원.
- `TutorialController.ClearAttachment`: 선택 기록 및 수단 일괄 해제.
- 신규 기록/수단의 5초 알림. 이어하기에는 신규 알림을 띄우지 않음.
- AI 토글·요금 안내·새 시작·상세 상태는 메뉴로 이동.
- 모달 열기 시 입력 포커스 해제. 바깥 클릭/닫기/Escape 지원. 모달 뒤 Enter 전송 차단.
- 기록 선택 등으로 대화 스크롤을 최하단으로 되돌리지 않음.
- 폰트 수정 유지, 다크/종이색 버튼 각각에 명시적 상태색 적용.
- `TutorialUIPreview`: 별도 Preview Scene에서 저장/API 없이 화면 PNG 출력.
- README, 실행 안내, 구현 명세 갱신. `docs/tutorial-ui.md` 신설.

## 검증

- 스크립트 독립 컴파일 통과.
- 기존 튜토리얼 NUnit 27개 통과. 게임 규칙·저장·응답 파싱 회귀 확인.
- 실제 Unity UI 이미지 렌더링 결과는 최종 확인 후 아래에 기록.
- 실제 키보드/마우스 클릭·네트워크 대화는 수동 확인 대상.

## 시각 검증 결과

- 실제 Unity 배치 실행에서 프로젝트/에디터 스크립트 재컴파일 및 이미지 출력 성공, 종료 코드0.
- `Logs/ui-preview/dialogue.png`, `journal.png`를 직접 확인했다(1440×900).
- 첫 출력에서 최신 대사의 하단 잘림과 선택 표시용 체크 기호의 누락 글리프를 발견했다.
- 런타임 LateUpdate의 최종 레이아웃 후 스크롤 보정과 `[선택]` 텍스트 표시로 수정하고 다시 렌더링해 확인했다.
- 최종 로그에 스크립트 컴파일 오류, 예외, 누락 글리프 경고가 없음을 확인했다. 라이선싱 클라이언트의 별도 경고는 있었지만 미리보기 출력과 정상 종료를 막지 않았다.
- 실제 클릭·입력 포커스와 작은 해상도 테스트는 별도 수동 확인으로 남는다.
