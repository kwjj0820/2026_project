# 첫 튜토리얼 설계

## 목적과 완료 기준

수집 → 연결 → 활용을 한 의뢰 안에서 경험한다. 자유 입력은 거짓말·아는 척·행동 제안을 허용하지만, 발언만으로 증거나 세계의 사실이 생기지는 않는다. 여관에서 잠들어 완료 화면에 도달하면 이번 개발 범위가 끝난다.

## 설정 기준

- 캐릭터와 월드 데이터는 별개다. 검은 처음부터 가진 평범한 장비다.
- 튜토리얼은 평범한 하루다. 딸은 며칠 묵은 모험가에게 식사를 가져오고 생활 정보를 알려준다.
- 삭제 시 자아·조작권을 잃은 캐릭터가 튜토리얼 세계를 소거하는 설정은 후속 이야기다. 이번 대화에는 공개하지 않는다.
- 추적자는 멸망한 세계를 기억하지만 여관 이후 반복 회차는 기억하지 않는다.
- 대사는 짧고 생활적으로 쓴다. 인물이 감정을 직접 해설하거나 모든 문장을 복선으로 말하지 않는다.
- 여관 주인 딸의 이름, 정확한 무기 접촉 시점, 본편 첫 대면의 상세는 미정이다. 이번 의뢰를 확정 세계관의 모든 내용으로 취급하지 않는다.

## 사건과 인물

| 인물 | 아는 것 | 모르는 것 |
|---|---|---|
| 여관 주인의 딸 | 두 상자를 주문했고 하나만 받음 | 배달원이 내려놓은 정확한 장소 |
| 길드 접수원 | 배송 확인 의뢰와 주문 사본 | 현장과 누락 원인 |
| 배달원 | 두 상자를 따로 옮김, 배달표 보유 | 문을 착각했다는 사실은 확인 전에는 모름 |
| 가게 주인 | 자기 창고에 주문하지 않은 상자가 있음 | 주문 번호를 대조하기 전에는 주인을 모름 |

진상은 오배송이다. 두 상자는 실제 운송됐지만 하나가 여관 옆 가게 창고에 놓였다. 도둑이나 음모는 없다. 단순 사건으로 정보 종류와 근거의 역할을 가르친다.

## 진행

1. **room**: 아침 식사, 여관 부탁, 짐 조사. 등록증으로 모험가임을 확인한다.
2. **guild**: 배송 확인 의뢰 수락. 아침 부탁을 놓쳐도 주문서 사본을 받는다.
3. **yard / alley**: 배달원 대화와 골목 조사는 순서를 바꿀 수 있다.
4. **기록 연결**: 진술과 두 출입문을 연결한다. 가능성이 등록되며 진상이 자동 확정되지는 않는다.
5. **배달원에게 제시**: 실제로 내려놓은 문을 확인한다. 창고 방문이 열린다.
6. **store**: 상자 표식 조사. 배달표와 연결해 소유권 확인 근거를 만든다.
7. **가게 주인에게 제시**: 식재료 회수. 근거 없이 가져가겠다는 주장만으로는 회수되지 않는다.
8. **inn**: 보고·전달, 저녁 반응, 취침. 아침 식사 여부에 따라 딸의 말이 달라진다.
9. **complete**: 완료 표시. 삭제나 본편, 사망·회귀는 시작하지 않는다.

## 기록과 연결 규칙

| ID | 종류 | 출처 / 내용 |
|---|---|---|
| adventurer | 물건 | 방의 길드 등록증. 이동 준비의 근거 |
| order | 문서 | 여관/길드. 주문17, 두 상자 |
| testimony | 증언 | 배달원. 두 상자를 여관 뒤에 놓았다는 주장 |
| delivery_slip | 문서 | 배달원. 두 상자의 주문 번호 |
| doors | 관찰 | 골목. 여관 부엌과 가게 창고의 서로 다른 문 |
| crate | 물건 | 창고. 17이 적힌 상자 표식; 아직 소유하지 않음 |

| 입력 두 개 | 활용 수단 ID | 결과 |
|---|---|---|
| testimony + doors | wrong_store | 오배송 가능성. 배달원에게 확인할 질문이 생김 |
| crate + delivery_slip | ownership | 주문과 상자 표식의 일치. 가게 주인에게 회수 근거로 사용 |

순서는 무관하다. 미수집·동일 기록 조합은 거부한다. 무관한 조합에는 불이익이 없다. 중복 연결로 수단이 늘어나지 않는다. 현재는 작성된 두 조합만 인식하며 임의 조합을 AI가 새 규칙으로 생성하지 않는다.
