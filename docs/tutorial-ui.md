# 게임북 UI

## 화면과 조작

검은 여백 안에 좁은 읽기 열을 두고, 장소 → 상황 설명 → NPC 초상화 → 이름과 대사 → 한 줄씩 쌓인 선택지 순서로 배치한다. 상황 설명과 대사는 순서대로 타이핑한다. 마지막 페이지까지 읽으면 선택지와 ‘직접 입력하기’가 나타난다. 입력창을 펼치면 선택지 자리를 사용하며 둘이 겹치지 않는다. 하단에는 기록장·소지품·대화 로그·설정을 고정한다. 현재 목표는 소지품 메뉴에서 확인한다.

- 본문 클릭 / Space: 표시 중인 페이지를 즉시 완성. 이미 완성됐다면 다음 페이지로 이동.
- 기록장: 기록을 최대 두 개 선택해 연결하고, 등록한 활용 수단을 눌러 대화에 첨부.
- 근거 제시: 읽기가 끝난 후 첨부 영역에서 실행. 해제는 첨부 수단과 선택 기록을 모두 해제.
- 소지품: 검·여행 가방·조사한 등록증·회수 후 미전달 식재료를 확인. 증언/물건의 조사 기록을 모두 물리적 소유물로 취급하지 않는다. 장비 교체·아이템 사용은 미구현.
- 대화 로그: 이전 대화를 스크롤하여 확인.
- 설정: AI 자유 대화, 글자 속도, 즉시 표시, 새 시작. AI는 기본 OFF이며 활성화한 실제 전송에 비용이 발생.
- 메뉴 닫기: 닫기 버튼, 바깥 클릭, Escape. 입력 중이 아니면 Escape로 설정을 열 수 있음.

기록장·소지품·로그·설정은 타이핑 중에도 열 수 있고 그동안 글자 표시는 정지한다. 입력 포커스를 해제하여 뒤쪽 입력창의 Enter 전송을 막는다. 작성 중인 입력은 유지한다.

## 타이핑과 페이지

글자 속도는 느리게 22자/초, 보통 42자/초, 빠르게 72자/초를 순환한다. 즉시 표시를 켜도 페이지 넘김은 유지한다. 긴 텍스트는 TMP Page 모드로 분할하며 마지막 페이지가 끝나기 전까지 선택지·입력·직접 제시는 숨긴다. 한 번의 완성 클릭으로 다음 행동이 실행되지 않도록 본문과 선택지의 입력 대상을 분리하고 같은 프레임의 중복 넘김을 막는다.

AI 응답 대기는 타이핑과 별개다. 응답을 받아 검증한 뒤 타이핑을 시작한다. 네트워크 오류 시 기존 장면과 입력은 유지하고 선택/입력을 다시 허용한다. 현재 버튼은 작성된 합법 행동이며 AI 생성 추천 선택지는 아니다.

## 구현과 저장

주 변경은 TutorialView.cs다. TextReveal은 Unity 비의존 문자 수/시간 누적 모델이며 TMP가 계산한 문자 개수를 사용한다. GamebookContent는 첫 큰따옴표 앞의 짧은 상황 설명을 분리한다. 대사 뒤의 서술은 순서를 바꾸지 않고 본문에 유지한다. 긴 도입부나 화면 높이를 넘는 도입부는 페이지 본문으로 돌려 잘림을 방지한다. 원본 대화/저장 형식은 바꾸지 않는다. 새 장면 객체가 생겼을 때만 시작하므로 기록 선택과 메뉴 열기는 표시를 리셋하지 않는다.

속도와 즉시 표시는 PlayerPrefs의 tutorial.reader.speed, tutorial.reader.instant에 저장한다. 게임 진행 초기화와 별개다. 모달 열림, 분류, 첨부, AI ON/OFF, 현재 페이지/글자 위치는 저장하지 않는다. 이어하기에서는 마지막 장면을 처음부터 다시 표시한다.

기록은 증언/증거/관찰로 분류한다. 분류를 바꿔도 선택 두 개는 유지된다. 새 기록/근거의 5초 알림을 제공하며 이어하기에는 기존 기록을 새 획득으로 알리지 않는다.

중앙 화면은 검정에 가까운 배경, 아이보리 글자, 구리색 강조, 회색 선택지를 사용한다. 기록장은 종이색과 짙은 글자를 사용한다. 원본 TTF, 동적 SDFAA/padding9, 전용 머티리얼과 명시적 버튼 상태색을 유지한다.

## 초상화 교체

`Assets/Resources/UI/TutorialPortraits.asset`을 선택하고 Inspector의 Entries에서 인물별 Portrait를 교체한다. Speaker는 현재 이름인 `여관 주인의 딸`, `길드 접수원`, `배달원`, `가게 주인`과 일치해야 한다. 이미지 Import Settings의 Texture Type은 Sprite로 설정한다. 서브컬처풍 정식 일러스트도 같은 슬롯에 연결하면 된다.

지금은 기존 stranger_confused/stranger_angry 밈 고양이 Sprite를 임시 연결했다. SoftPortrait가 비율을 유지하고 가장자리를 투명하게 처리하므로 원본 이미지는 수정하지 않는다. 카탈로그 누락 시 알려진 NPC는 기존 고양이로 대체한다. 이미지가 없거나 인물 없는 조사 장면, 450자 이상의 긴 글에서는 넓은 텍스트 배치로 돌아가며 이전 초상화를 남기지 않는다. 표정 전환·Live2D·립싱크는 이번 범위에 없다. 배포 전에 임시 이미지의 사용 권한을 확인하거나 교체한다.

## 검증과 미리보기

Tools → Tutorial → Export UI Previews는 별도 Preview Scene에서 아침 첫 대화(morning.png)·뷰어·기록장·로그·소지품·긴 본문을 PNG로 출력한다(Logs/ui-preview/). 실제 저장/API/활성 씬은 변경하지 않는다. Play 종료 상태에서 실행한다. 선택지 숨김/완성, 긴 본문 페이지 분할, 아침 초상화 연결을 함께 점검한다.

Tools/Test-Tutorial.ps1은 기존 게임 규칙과 타이핑·본문 분리 모델의 NUnit 테스트를 독립 실행한다. Unity 실행/이미지 검증과는 별개다. 이번 결과는 devlog/2026-10-16-gamebook.md를 참조한다. 이전 PNG가 남아 있다면 새 렌더링 전에는 이전 UI 이미지일 수 있다.

수동 확인:

- 타이핑 종료 전 선택지가 없고, 클릭·Space가 즉시 완성만 하는지.
- 긴 응답이 잘리지 않으며 마지막 페이지 후에만 선택지가 나타나는지.
- 메뉴를 열면 타이핑이 멈추고, 닫으면 남은 위치에서 이어지는지.
- 직접 입력 중 Space가 글자를 완성하거나 페이지를 넘기지 않는지.
- 모달 내부 클릭은 닫힘을 유발하지 않고 바깥 클릭은 닫는지.
- 속도·즉시 표시가 재실행 후 유지되는지.
- 작은 Game 화면에서도 본문·선택지·하단 메뉴가 겹치지 않는지.
