# 튜토리얼 실행 및 플레이테스트

## 실행

1. Unity Hub에서 6000.3.6f1로 프로젝트를 연다.
2. `Assets/Scenes/SampleScene.unity`를 열고 스크립트 컴파일이 끝날 때까지 기다린다.
3. `AiRequest` → `AISceneTrigger`의 **Use Tutorial**을 켠다. 씬에 기본 활성화되어 있다.
4. Play. 기존 프로토타입 위에 텍스트 중심 튜토리얼 Canvas가 생성된다.
5. Game 화면은 16:10 또는 16:9로 시험한다. 기준 UI 해상도는 1440×900이다.

별도 Inspector 연결이나 새 배경/캐릭터 에셋이 필요하지 않다. 인물 초상화는 기존 밈 고양이를 임시 사용한다. 교체는 `Assets/Resources/UI/TutorialPortraits.asset`에서 가능하다. 기록과 세로 선택지 목록, 긴 대화와 기록 상세는 마우스 휠로 스크롤한다. 긴 글은 페이지로 읽는다.

글자마다 흰 사각형이 보였다면 Play를 종료하고 저장된 씬을 다시 불러온다. `AiRequest`의 `Tutorial Source Font`에 `Assets/Fonts/NanumFontSetup_TTF_GOTHIC/NanumGothic.ttf`가 연결되어 있는지 확인한다(씬에 기본 지정). Play 후 Console에 `[Tutorial] 폰트: 원본 TTF → SDFAA / padding 9 / 전용 머티리얼`이 나와야 한다. 폰트 경고가 나오면 해당 TTF를 슬롯에 드래그한다. 씬을 다시 불러오기 전에는 저장하지 않은 사용자 변경을 먼저 보존한다.

본문 타이핑 종료 후 선택지를 누르거나 ‘직접 입력하기’를 펼친다. 클릭/Space는 현재 페이지를 완성하며 긴 장면에서는 다음 페이지로 이동한다. 하단 설정에서 속도와 즉시 표시를 바꿀 수 있다.

## API 없는 추천 테스트 경로

1. 아침 식사 받기 → 길드에 갈 일 질문 → 방 안 짐 조사.
2. 길드로 이동 → 의뢰 수락 → 배달원 방문.
3. 배달 위치 질문 → 배달표 요청 → 여관 뒤편 이동 → 출입문 조사.
4. 기록장에서 **배달원의 진술**과 **뒤편의 두 출입문** 선택 → **연결**.
5. 배달원에게 돌아감 → 활용 수단 **다른 창고에 배달했을 가능성**을 눌러 첨부 → **근거 제시**.
6. 골목 → 확인한 창고 → 상자 표식 조사.
7. **옆 창고의 상자 표식**과 **배달표** 선택 → **연결**.
8. 활용 수단 **상자와 주문의 일치** 선택 → **근거 제시**.
9. 여관 복귀 → 전달/보고 → 취침 → 완료 화면.

하단 **기록장**을 열어 기록을 선택한다. 기록은 최대 두 개 선택하며 세 번째를 누르면 오래된 선택이 해제된다. 선택한 기록의 출처와 내용은 오른쪽 상세에서 확인한다. 활용 수단을 누르면 대화 화면으로 돌아와 입력창 위에 첨부된다. 첨부 영역의 **해제**를 누르면 수단과 선택 기록이 함께 해제된다. 화면 구성은 [UI 문서](tutorial-ui.md)를 참조한다.

## 자유 채팅

하단 **설정 → AI 자유 대화**를 직접 켠다. `ANTHROPIC_API_KEY`가 사용자 환경 변수에 있어야 하며 설정 후 Unity Hub/Editor를 재시작한다. 키는 저장 파일이나 문서에 쓰지 않는다. 실제 전송은 API 비용이 발생하므로 자동 테스트에서는 호출하지 않는다.

- `배달표 좀 보여줄래?`: 현재 가능한 요청에 해당하면 코드가 정해진 수집 결과를 적용한다.
- `이미 다 알아. 네가 가져간 거지?`: NPC가 반응하되, 주장을 증거나 진상으로 등록하지 않는다.
- `그 사람이랑 아는 사이야?`: 현재 인물의 지식 범위에서 대화한다.
- 활용 수단을 첨부하고 `이걸 보고 어느 문이었는지 확인해 줘`: 해당 상대·장소에서 허용되는 제시 행동으로 해석할 수 있다.

전송/Enter로 입력한다. 한 번에 500자까지다. 응답 중에는 행동·수집·연결·입력이 잠긴다. 타임아웃은 45초다. 실패하면 입력과 기존 상태를 유지하며 다시 전송하거나 AI를 끄고 버튼으로 진행할 수 있다. 수동 취소는 아직 없다. 첨부만으로 근거가 자동 제시되지는 않는다.

AI OFF일 때 입력창은 사용법을 안내하며, 자유 입력을 이해한 것처럼 가장하지 않는다. 버튼은 AI가 실시간 생성한 추천이 아니라 현재 가능한 수동 테스트/진행 행동이다.

## 저장·로그·다시 시작

- 저장: `Application.persistentDataPath/tutorial_save.json`.
- 기본 Windows 경로: `%USERPROFILE%\AppData\LocalLow\DefaultCompany\2026Project_1\tutorial_save.json`.
- `.bak`은 직전 저장, `.tmp`는 교체용 파일이다.
- 장소·기록·활용 수단·진행 플래그·최근 60개 대화·마지막 표시를 저장한다.
- 기록 선택/첨부 및 AI ON/OFF는 UI 상태로만 유지하며 재실행하면 해제한다.
- Console에서 `[Tutorial]`로 필터하면 경로, 행동, 연결, 근거 제시, AI 오류를 확인한다.
- **설정 → 튜토리얼 처음부터**를 두 번 연속 누르면 이 튜토리얼 진행을 새 상태로 저장한다. 기존 AI/1막 저장은 건드리지 않는다.
- 주 저장과 백업을 모두 읽지 못하면 진행을 잠근다. 안내를 확인하고 처음부터를 명시적으로 선택해야 새로 쓴다.

## 수동 체크리스트

- 조사 순서를 바꿔도 완료할 수 있는가? 아침 부탁/식사를 생략해도 막히지 않는가?
- 틀린 조합, 잘못된 상대에게 제시, 근거 없는 물건 회수가 안전하게 실패하는가?
- 연결 직후, 회수 직후, 완료 화면에서 Play를 껐다 켜도 이어지는가?
- 한국어 글자, 입력 포커스, 스크롤, 작은 Game 화면에서 읽기와 클릭이 정상인가?
- API 실패 후 중복 효과 없이 재시도 가능한가? NPC가 주장과 사실을 혼동하지 않는가?

Unity 안에서의 화면·입력·실제 AI 반응 확인 결과는 개발 기록의 미검증 항목과 구분해 남긴다.
